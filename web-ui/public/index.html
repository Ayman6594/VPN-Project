About this Project

Architecture and technology stack

What is this?

A self-hosted SSL VPN server built with ocserv (OpenConnect Server), compatible with Cisco AnyConnect and FortiClient-style clients. The admin panel is built with Node.js + Express and served through an Nginx reverse proxy — all running in Docker containers.
